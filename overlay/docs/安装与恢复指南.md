# 定位助手安装与恢复指南

本版本为开发验证版。构建成功不表示定位或自身续签已通过真机验收。

## 首次安装

1. 下载 GitHub Actions 的 `LocationAssistant-unsigned-for-local-signing` 产物，解压得到 IPA。它需要本地重新签名，不能直接点击安装。
2. 每台 iPhone/iPad 分别连接电脑，解锁并信任电脑，开启开发者模式；使用 iloader 的 Import IPA 签名安装。安装工具的程序和下载放在 E 盘，既有授权允许 iloader 的系统运行数据使用 C 盘。
3. 在设备上安装 LocalDevVPN 并连接。日常定位与续签按 Wi-Fi 使用流程测试。
4. 用 iloader 为该设备生成配对文件，在 App「设置」导入。独立应用标识可能不会被 iloader 自动识别为 SideStore，因此先手动导入文件；不要导入其他设备的文件。
5. 重新打开 App，点击检查定位连接。若签名账号已有证书，先在「设置 → 导入续签证书」选择原签名工具导出的完整 `.p12/.pfx` 或 SideStore 加密账号备份 `.sideconf`，输入导出时设置的文件密码。然后在「续签」中登录证书所属的 Apple 签名账号。配对文件与公开证书没有签名私钥，不能代替完整证书。不得将账号、私钥或配对文件上传公开仓库。

## 已有证书与登录错误（0.1.1）

新版缺少已有证书的私钥时会阻止继续申请或撤销证书，避免影响其他已安装 App。导入只在本设备进行，账号备份只提取证书，不导入账号密码或 anisette 信息。导入成功仅表示文件已保存，仍需登录核对证书所属账号及有效性，并完成实际续签。

原版 SideStore 的入口：`Settings → Certificate Management`，先确认对应证书标有 `Keys: public + private`，再在证书列表中长按卡片，选择 `Export Certificate → Export Full (.p12)`，自己设置文件密码并保存到“文件”。随后在定位助手的“设置 → 导入续签证书”选择该文件，输入同一文件密码。证书详情页不是导出入口，iloader 的证书列表也没有导出按钮；不要点撤销。`Backup & Restore` 也可导出加密账号备份，建议关闭包含 Apple 密码的选项。不同版本没有相应入口时先保留现有证书和 App。

从 0.1.0 升级：用相同签名账号覆盖安装新 IPA，不先删除旧 App；升级后检查收藏和配对仍保留。若原版 SideStore 安装 IPA 时嵌入其签名证书，新版会尝试读取，但须真机验证，不保证各版本均如此。

## 修改位置

0.2.5 已将固定开发者映像包含在安装包中，无需设备访问 GitHub 下载。在“设置 → 准备本地开发者映像”可单独校验并建立缓存；保持 App 在前台，完成后连接 LocalDevVPN，再准备定位开发服务。挂载中的 Apple 个性化服务仍可能需要网络。覆盖升级时不先删除 App，不重新创建证书。

进入「定位」，搜索或选点，亦可输入 WGS-84 经纬度。地图与搜索结果按中国地图坐标规则转换；首次应通过已知地点校验偏移。选点不会立即修改系统位置，只有点击「开始模拟」才执行。

允许后台定位后可切换到苹果地图、高德或其他 App 查看当前位置。系统限制、App 自身定位方式或后台暂停可能影响效果，不能保证所有 App 同步显示。

## 清除模拟

保持 LocalDevVPN 连接，点击「清除模拟定位」。收到成功响应后，在地图 App 触发重新定位，确认真实位置恢复，再关闭 VPN。

清除失败或状态未知时，不要将关闭 App、关闭 VPN 视为清除成功。重新连接 VPN 后再清除；仍失败时关闭 VPN、重启设备，先检查真实位置，暂勿再次开启模拟。

如果重启后已在地图中确认真实位置恢复，但 App 仍显示上次模拟状态未知，可在「设置 → 重启后确认真实位置已恢复」记录你的确认，再更换配对文件或 IP。这个操作只解除本 App 的状态锁定，不执行底层清除，也不代表 App 自动验证过位置。

## 自身续签

连接 Wi-Fi 与 LocalDevVPN，在到期前点击「刷新自身签名」。刷新前会先清除模拟；清除失败则不继续续签。完成后核对“续签状态”和“最近续签回执”，检查收藏、配对仍保留。快速续签只安装设备上的描述文件，App 内日期可能不变，不应仅据此判定失败。重开后显示的是本设备保存的最近操作记录，不能据此保证 Apple 会话当前有效。

0.2.4 修复首次签名初始化误运行历史维护任务、删除刚导入私钥的问题。旧版已经删掉的私钥无法凭空恢复；覆盖安装后可用先前保存的完整 p12 重新导入，无需撤销或重新创建同账号证书。只有登录或导入文件，没有实际续签回执，不能视为已完成续签。

免费签名通常约 7 天有效，建议每 3～5 天手动刷新。过期后 App 可能无法启动，需电脑重新签名安装。每台设备独立维护，刷新时本 App 可能退出；不要删除重装来代替刷新，以免丢失配置。

## 兼容与性能

最低安装版本暂定 iOS/iPadOS 17.4，仅构建 arm64 设备包。首测 iPhone 12 / iOS 18.6.2，iPad 9 / 用户提供的 iPadOS 26.6。其他版本须分别验证。

地图懒加载、搜索 400ms 防抖、取消过时请求、收藏文件异步保存。iOS 26 模拟期间保留上游每 4 秒提交位置的兼容行为，不刷新地图、不重新搜索；后台支持只在模拟期间启用。
