# 0.2.3 映像提前下载与诊断

## 本次问题与调整

0.2.2 的设备验证中，准备映像失败，只显示泛化的“检查网络及设备空间”。旧版没有保存底层错误，无法追溯确认最终原因。用户随后在手机上开启可访问外网的 VPN，Safari 能显示同一下载主机的公开文本；这说明需要把下载网络与设备连接分开处理，不能把电脑可达等同于手机可达。

设置新增“提前下载开发者映像”。该操作不连接设备、不启动定位隧道、不要求配对或 Apple 登录。可先在能够访问下载源的网络下完成约 17 MB 的下载及 SHA-256 校验，完成后再切换到 LocalDevVPN，执行“准备定位开发服务”。

原有准备流程仍先查询设备挂载状态；需要映像时复用同一缓存校验函数。已提前下载并校验的文件不重复联网，缓存损坏才重下。下载完成只代表文件可用，不代表映像已挂载或定位已经生效。

## 操作顺序

1. 在能够访问下载源的网络下，打开“设置 → 提前下载开发者映像”。保持前台，到定位页查看进度。
2. 等显示“映像文件已下载并校验”后，再切换到 LocalDevVPN。
3. 返回“设置 → 准备定位开发服务”，到定位页核对挂载状态。定位、恢复和续签仍需分别验证。

切到后台会取消未完成下载；完成的已验证文件保留，下一次只补缺失文件。不要在下载未完成时切换 VPN。

## 错误信息

分开记录读取配置、创建缓存、下载、校验、保存等阶段。对网络错误保留 NSURLErrorDomain 与代码，对 HTTP 错误保留状态码，对存储错误保留安全错误域及代码。达到下载大小限制时明确提示，不混作用户取消。

“设置 → 脱敏诊断信息”仅保存白名单阶段/资源名/错误域和数字代码，不保存底层 localizedDescription、userInfo、URL、文件路径、账号、私钥、配对或定位坐标。

## 验证范围

新增检查覆盖：提前下载入口不依赖设备/账号；完整缓存跨网络使用不再下载；中断后保留已校验文件；超时、HTTP、缓存目录失败、存储空间错误的分类；错误信息中的敏感字符串脱敏；真实 URLSession 超限响应中止。原有 DDI、原生包装器故障注入及 100 次资源释放循环保留。

0.2.3 尚未进行实际设备验证。0.2.2 已在 iPhone/iOS 18.6.2 安装和启动，但映像准备失败，未提交模拟位置；不把这些结果记为 0.2.3 已通过。此前 iloader 的账号登录成功也不等于 App 内登录或续签成功。

下载网络仍需用户实际可访问固定公开源；Native 映像个性化、真实挂载、模拟及恢复、后台和续签均不能仅凭编译/模拟测试确认。
